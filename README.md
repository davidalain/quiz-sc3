# Quizzes do Subcurso 3 · MobLab 2.0

Quizzes online das aulas do Subcurso 3 do MobLab 2.0 (Programa Mover – Linha VI – Conectividade Veicular).

- Aula 1: [dia01/](dia01/)

A página envia as respostas a um servidor (Google Apps Script), que calcula a nota e as grava numa planilha. O gabarito não fica neste repositório.

Os arquivos são gerados por `gerar_quiz.py`, a partir dos arquivos `.md` de cada quiz.
